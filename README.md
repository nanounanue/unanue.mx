# unanue.mx

Personal website for Adolfo De Unánue — researcher in machine learning, operations research, and political economy.

## Tech Stack

- **Content**: Org-mode → Pandoc → Quarto
- **Hosting**: Codeberg Pages
- **CI/CD**: Woodpecker CI (builds on push to main)

## Local Development

```bash
# Convert org files and preview
make preview

# Build for production
make build
```
