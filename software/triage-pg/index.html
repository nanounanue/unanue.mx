Temporal machine learning for public policy, end to end inside PostgreSQL. A fork of the University of Chicago’s Triage in which cohorts, labels, features, temporal cross-validation and model governance are all expressed as SQL against the database that already holds the data, so a pipeline moves to production without leaving it.
