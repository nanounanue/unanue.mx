triage-pg

Temporal machine learning for public policy, end to end inside PostgreSQL. A fork of the University of Chicago’s Triage in which cohorts, labels, features, temporal cross-validation and model governance are all expressed as SQL against the database that already holds the data, so a pipeline moves to production without leaving it.

Python + SQL ·MIT ·v1.1.5 ·repo ·docs ·doi:10.5281/zenodo.22292553
Built for Case triage at a state prosecutor’s office; early-warning pilots in health and education.
featurizer

Deep Feature Synthesis compiled to SQL. Given a relational schema and an entity graph, it generates the point-in-time-correct feature matrix as queries the database runs itself, so the database computes each feature as of a date rather than joining it after the fact.

Python + SQL ·Apache-2.0 ·v1.1.1 ·repo ·docs ·doi:10.5281/zenodo.22287185
Built for The feature layer under the triage-pg pipelines above.
